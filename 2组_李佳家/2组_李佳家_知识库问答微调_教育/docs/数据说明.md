# 数据集说明

## 1. 业务背景

本项目面向「知行学堂」在线教育平台的知识库问答场景：学员在 App / 官网提问，检索服务先召回若干制度条款，再由模型依据条款生成答案。业务对模型的核心要求不是“答得多”，而是：

1. 只依据召回资料回答，不编造政策、金额和期限；
2. 答案带有可核对的条款编号，方便客服复核；
3. 资料不足或新旧版本冲突时明确拒答，并告诉用户缺什么信息。

## 2. 知识库语料

原始语料位于 `data/knowledge/`，共 6 篇制度文档、37 个条款：

| 文档编号 | 文档名称 | 条款数 | 主要内容 |
| --- | --- | --- | --- |
| KB-EDU-001 | 课程体系与班型说明 | 6 | 班型、有效期、转班、资料、试听、设备要求 |
| KB-EDU-002 | 退费与转班政策 | 7 | 退费时限、材料、到账、限制、手续费、分期、争议 |
| KB-EDU-003 | 学习服务与督学规则 | 6 | 督学、请假补课、作业、一对一辅导、社群、投诉 |
| KB-EDU-004 | 直播课与回放规范 | 6 | 上课时间、回放、出勤、连麦、录屏、网络异常 |
| KB-EDU-005 | 证书与结业规则 | 6 | 结业条件、证书类型、发放、补办、复核、评优 |
| KB-EDU-006 | 发票与合同常见问题 | 6 | 发票类型、开票、修改、合同、退费发票、企业采购 |

每个条款包含以下结构化字段，供数据生成与自动评测共用：

- `cid`：条款编号，如 `KB-EDU-002-2.3`；
- `heading`：条款标题；
- `text`：条款原文（也是 RAG 检索片段）；
- `summary`：一句话摘要；
- `points`：2-5 条关键要点，用于计算要点覆盖率；
- `numbers` / `terms`：数字与行业术语，用于数字忠实度和术语准确率；
- `process`：办理步骤（部分条款）；
- `advice`：办理建议。

`data/knowledge_base.json` 是同一份语料的结构化版本，`scripts/kb_data.py` 是唯一数据源，修改语料后重新运行生成脚本即可得到新的数据集。

## 3. 五个能力维度

| 能力维度 | 对应要求 | 构造方式 | 样本数 |
| --- | --- | --- | --- |
| `term_format` 行业术语与格式适配 | 4.1.1 | 制度解释类问题 + 办理步骤类问题，答案按“结论 / 要点 / 依据 / 建议”或“步骤 / 注意事项”组织 | 112 |
| `faithful` 检索内容忠实回答 | 4.1.2 | 目标条款 + 2 条含不同数字的干扰条款，问题询问期限与费用，答案只能使用目标条款数字 | 112 |
| `multi_snippet` 多片段信息整合 | 4.1.3 | 24 组业务相关条款对（如转班 + 退费、请假 + 回放），答案整合两条依据 | 112 |
| `citation` 证据引用与出处标注 | 4.1.4 | 要求标注出处的提问，答案包含原文摘录与 `[条款编号]` | 112 |
| `refusal` 资料不足拒答 | 4.1.5 | 30 个知识库外问题（生成 100 条资料不足样本）+ 12 组新旧版本冲突，测试集含 3 条冲突样本 | 112 |

合计 560 条，按 84 / 12 / 16 切分为训练 / 验证 / 测试，每个能力维度在三个切分中都有覆盖。

## 4. 样本格式

训练文件为 JSONL，每行一条样本：

```json
{
  "id": "edu-citation-0007",
  "capability": "citation",
  "messages": [
    {"role": "system", "content": "你是知行学堂……只能依据资料回答……"},
    {"role": "user", "content": "【资料】\n【资料1】[KB-EDU-002-2.3] 退费到账时间：……\n\n【问题】请依据资料回答「退费到账时间」的规定，并标注依据条款编号。"},
    {"role": "assistant", "content": "根据资料，审核通过后 15 个工作日内按原支付渠道退回。……依据：[KB-EDU-002-2.3]"}
  ],
  "meta": {
    "capability": "citation",
    "answerable": true,
    "gold_refs": ["KB-EDU-002-2.3"],
    "context_refs": ["KB-EDU-002-2.3", "KB-EDU-003-3.1", "KB-EDU-004-4.5"],
    "terms": ["工作日", "原支付渠道", "顺延"],
    "key_points": ["审核通过后 15 个工作日内退款", "……"],
    "split": "train"
  }
}
```

- `messages` 直接用于 `tokenizer.apply_chat_template`；
- `meta.gold_refs` 是标准依据条款，用于计算引用召回率；
- `meta.key_points` 用于计算要点覆盖率；
- `meta.answerable` 区分可回答 / 应拒答样本。

检查项包括：消息角色完整、可回答样本必须带引用、引用条款必须出现在上下文中、拒答样本必须包含拒答表述、ID 不重复、训练集与测试集问题不重叠。

## 6. 复现方式

```bash
python scripts/generate_dataset.py   # 重新生成数据与语料 markdown
python scripts/check_dataset.py      # 数据质检
```
