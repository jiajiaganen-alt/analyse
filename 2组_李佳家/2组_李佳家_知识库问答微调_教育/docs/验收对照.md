# 验收对照

本项目对应任务文档第 4.1 节「知识库项目模型微调」，以下逐项对照能力要求、训练数据和评估重点。

## 一、能力要求对照

| 编号 | 要求 | 实现情况 | 证据 |
| --- | --- | --- | --- |
| 4.1.1 | 行业术语与回答格式适配：按行业术语、口径和输出格式回答（制度解释、产品说明、操作步骤） | 已实现。37 个条款、两种回答格式（解释 / 步骤），格式合规率由 0 提升到 1.000，术语准确率 0.867 | `docs/能力覆盖矩阵.md`、`测试截图/04_评测指标对比.png` |
| 4.1.2 | 检索内容忠实回答：严格依据检索结果，避免编造事实、数字、政策 | 已实现。每条样本带 2 条含不同数字的干扰条款，数字忠实度 1.000，干扰数字未出现在答案中 | `data/train.jsonl` 中 `faithful` 样本、`scripts/evaluate.py` 数字校验 |
| 4.1.3 | 多片段信息整合：合并多个片段、处理表述不一致和跨段落引用 | 基本实现。24 组条款对，4/5 测试样本正确整合并分别引用，1/5 退化为单条款回答，综合 0.805 | `report/samples.html` 第三个样例、`docs/训练与评测说明.md` 5.3 |
| 4.1.4 | 证据引用与出处标注：标注依据来源与条款位置 | 已实现。答案包含原文摘录 + `[KB-EDU-00X-Y.Z]`，引用 F1 0.941 | `测试截图/05_样例对比_基线与微调.png` 第一组 |
| 4.1.5 | 资料不足时拒答：无召回、弱相关、冲突时拒答并说明缺失信息 | 部分实现。30 个知识库外问题（100 条样本）+ 12 组新旧版本冲突（测试集含 3 条冲突样本）；资料不足 3/3 正确拒答，冲突样本 0/2（被历史版本数字误导），拒答维度综合 0.600 | `测试截图/05_样例对比_基线与微调.png` 第二组 |

## 二、训练数据对照

| 要求 | 实现 |
| --- | --- |
| 行业问答样例 | 37 个条款 × 5 类问法，`term_format` 112 条 |
| 标准术语表 | 每个条款标注 `terms`，用于术语命中率评测 |
| 不同格式的答案模板 | 解释型（结论/要点/依据/建议）与步骤型（步骤/依据/注意事项） |
| 用户问题、检索片段、标准答案、不可回答样例 | 全部包含；不可回答 112 条（资料不足 100 + 冲突 12），测试集含 3 条冲突样本 |
| 多段检索结果、跨文档问题、整合后答案 | 24 组相关条款对，`multi_snippet` 112 条 |
| 带来源编号的检索结果、带引用标注的答案 | 所有片段带 `[条款编号]`，引用类 112 条 |
| 无召回、弱相关、冲突召回和标准拒答样例 | 拒答类 112 条，含冲突型 |

## 三、评估重点对照

| 评估重点 | 指标 | 结果 |
| --- | --- | --- |
| 术语是否准确、格式是否稳定、是否符合业务口径 | 格式合规率、术语准确率 | 0.880 / 0.808 |
| 答案是否有依据、是否引入幻觉、是否遗漏关键条件 | 引用 F1、数字忠实度、要点覆盖率 | 0.950 / 1.000 / 0.888 |
| 信息整合是否完整、能否区分主次和条件 | 多片段综合得分、要点覆盖率 | 0.805 / 0.800 |
| 引用是否准确、答案与证据是否一致 | 引用精确率 / 召回率 / F1 | 1.000 / 0.883 / 0.941 |
| 拒答是否及时、是否指出缺失信息和下一步方向 | 拒答正确率（维度） | 0.600（资料不足 1.000 / 冲突 0.000） |

## 五、快速验收步骤

1. 打开 `report/index.html`，查看总览、数据集、训练、评测、样例对比 5 个页面；
2. 查看 `测试截图/` 中的 5 张截图，核对模型、样本量、指标；
3. 运行 `python scripts/check_dataset.py`，确认 420 / 60 / 80 与质检通过；
4. 运行 `python scripts/evaluate.py --tag tuned --adapter outputs/lora_adapter --limit 5`，复现 0.859 综合分；
5. 打开 `outputs/train_console.log`，核对 60 步训练日志与 13.2 分钟耗时。
