## 4. 2.2.4 任务状态与执行流程

| 要求 | 实现 | 验证 |
| --- | --- | --- |
| 应用状态至少 stopped/starting/running/stopping/failed | `ProcessManager` 状态机 + `transitions` | 测试断言 starting→running、stopping→stopped；状态页展示 |
| 论坛状态至少 idle/running/stopped/failed | `ForumCollector.status` | 测试 `test_forum_start_log_stop` |
| 系统状态至少 offline/starting/online/shutting_down | `ProcessManager.system_status` | 测试 `test_system_shutdown_and_start` |
| 系统启动后允许独立启动应用 | 每个应用独立接口与线程 | 控制台逐卡启动；测试逐个 start |
| 每个应用独立保存状态、stdout/stderr | `runtime/apps/{app}.log`，`[stdout]`/`[stderr]` 标记 | 测试 `test_output_and_test_log_after_search` |
| 停止后不再接收新任务，输出/日志保留 | `manual_stop` 阻断自动拉起；日志不删除 | 测试 `test_search_blocked_after_manual_stop` |
| 报告与图谱按报告编号回查 | `GET /api/graph/{report_id}`、`/api/report/{report_id}` | 测试 `test_graph_latest_and_by_report` |

## 8. 2.2.8 采集与分析规则

| 要求 | 实现 |
| --- | --- |
| 每次检索保存主题词、执行时间、来源摘要、分析输出 | `reports/{id}/search.json` + `outputs/apps/latest.txt` |

| 报告结论可追溯 | 每章节与建议带 `[Sxx]`，文末来源清单；图谱节点带引用 |

## 13. 其他硬性约束

| 约束 | 实现 |
| --- | --- |
| Python 3.12 + FastAPI/uvicorn + 标准库 sqlite3/JSON/threading | 使用 JSON 文件 + threading；未引入 ORM、数据库或第三方前端框架 |
| 前端纯原生、禁止 CDN/外部字体/图片 | 仅本地 CSS/JS/内联 SVG，系统字体栈 |
| 图谱 SVG 自绘、图表内联 SVG/CSS | `graph.js`、`search.js` 内联 SVG |
| 不使用大模型 API（离线） | 确定性规则流水线，无外网请求 |
| 端口固定 8714 | 启动命令、README、截图脚本一致 |
| 至少 2 个主题、每个 30-60 条来源、时间近 30 天 | 48 条 + 36 条；使用 `hours_ago` 相对当前时间生成 |
| 主主题图谱 15+ 节点、20+ 边 | 51 节点 / 91 边 |
| 测试至少 14 个用例且全过 | 27 passed，见 `docs/测试记录.md` |
| 8 张真实截图 >40KB | 见 `测试截图/` 与测试记录 |
| `/graph-viewer` 与 `/graph-viewer/{id}` 可访问 | 返回单页应用，测试 200 |
